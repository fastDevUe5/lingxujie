## 2. 区域结构（照它的"三层"逻辑，不照它的具体地图）

墨香是"主城 → 野外练级带 → 门派/副本"的三段式。我们 P0 只做一条完整的三段线：

| 段 | 我们的区域 | 功能 | 规模（P0） |
| --- | --- | --- | --- |
| 入口 / 教学 | **山门**（城门 + 石阶 + 广场） | 出生点、操作教学、世界观交代 | 100 × 100 m |
| 生活 / 任务 | **村落**（街巷 + 民居 + 水塘园林） | NPC、商店、交任务、休整 | 170 × 170 m |
| 战斗 / Boss | **后山道场**（林间空地 + 石台） | 打怪、Boss 战、学新技能 | 120 × 120 m |

动线：**山门 → 村落 → 后山道场**，一条主路串起来，不做岔路迷宫（P0 目标是"闭环可通"，不是探索）。

## 3. 每个区域要有的东西（照墨香的密度取最小值）

**山门**
- 城楼 1 座（已有素材：城门包）
- 石阶 + 广场（石板铺装已有）
- 引导 NPC 1 个（交代"宗门召你回山"）
- 路牌 1 个（指向村落）

**村落**
- 民居 3–5 栋（邑城 + Changwon）
- 水塘园林 1 处（洗然亭已摆好）
- NPC 3 个：任务发布、杂货商、闲谈（给世界观）
- 街巷道具：灯笼、水缸、条凳、竹篱（Heritage Props）

**后山道场**
- 林间空地 + 石台（Boss 场地）
- 小怪 6–8 只（灵兽近战 / 邪修远程，已有）
- **Boss 1 只**（道场守关，2 阶段）
- 战后掉落 + 学会新技能

## 5. 任务链（P0 唯一一条主线，5 环）

1. 【山门】引导 NPC：「宗门召你回山，先去村落找李掌柜」
2. 【村落】李掌柜：清掉村外 3 只灵兽 → 交任务
3. 【村落】得到「邪修在道场作法」情报 → 前往后山
4. 【道场】击败邪修头目（Boss）
5. 【道场】拾取「功法残卷」→ 学会新技能 → P0 结束

预计时长：**15–20 分钟**。
