## 4. 已否决（不要再提）

| 方案 | 否决原因 |
| --- | --- |
| 卡通/toon 渲染 | 已否，见 gotcha #50 |
| 用 JPG 贴花做地面脏迹 | 无 alpha，变成不透明"纸带"（gotcha #57） |
| 泥土/草地色块方片铺地 | 明显的"纸带感" |
| 椭圆盆造池塘 | 驳岸是不规则形状，椭圆永远对不上；正解是用包自带岸网格 |
| 太阳染成橙色 | SkyAtmosphere 用太阳颜色给天空上色，整片天变橄榄色（gotcha #54） |
| 整包买入"完整游戏工程"（Lyra/MMO Kit 等） | 蓝图堆的架构与我们 C++ 冲突；Lyra 只是 GAS 教材 |
