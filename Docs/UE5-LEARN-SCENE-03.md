## 二、🔴 两次布局失败，同一个错误

### 2.1 第一次（原来的位置）

```
Prop_0 (-300, -400)   Prop_1 (0, -200)   Prop_2 (300, -400)
Prop_3 (600, -100)    Prop_4 (-700, 100) Prop_5 (900, 200)
```

**→ 全挤在**玩家脚下**（y 从 -400 到 200，玩家在 -800）。只看到 2 个。**

### 2.2 第二次（推到远处）

```
Prop_0 (-1200, 600)   Prop_1 (-600, 1400)  Prop_2 (0, 1800)
Prop_3 (700, 1400)    Prop_4 (1300, 700)   Prop_5 (1800, -200)
```

**→ 结果：一个大圆柱挡住半个画面，其余挤在右边缘。**

### 2.3 🔴 根因：**我把「宽」放错了轴**

**相机 `yaw 0` 看的是 **+X** 方向。
→ **画面的**宽度**是沿 **Y 轴**的。**
→ 我却把物体沿 **X** 铺开（600→1800），在 **Y** 上只给了 600→1800 —— **全挤在右侧。**

**✅ 正确：**
- **Y 轴 = 画面的宽**（铺开用）
- **X 轴 = 景深**（远近用）

**视野换算：** 90° FOV 下，距离 d 处的可见宽度 ≈ **2d**。

## 六、这一块学到什么

**1. 🔴 用「自己挑的相机」判断场景，会误判。**
编辑器相机能看到构图，玩家看不到 —— **判据必须是玩家视角。**

**2. 🔴 相机的**宽**是沿相机的**右方向**，不是世界 X 轴。**
`yaw 0` 朝 +X 看 → 画面宽沿 **Y**。**这个我搞错了两次。**

**3. 🎯 90° FOV 下，距离 d 处可见宽度 ≈ 2d。**
这是构图的基本算术 —— 有它才能算出物体该摆多远、铺多宽。

**4. 迭代是必要的。** 三次布局，每次看图才发现问题。

**5. 同一个错误连犯两次** —— 因为第一次我只改了「远近」，没改「宽沿哪个轴」。
