# UE5 学习 · 物理（第二块）：滚不滚，由形状和阻尼决定

> **上一块的疑问：「球为什么滚了 5 米」。这一块做了对照实验，**我的假设被推翻**，
> 并且找到了**可操作的解法**。**
>
> **日期：2026-11-27 · UE 5.8.4**

---

## 一、上一块留下的疑问

**第一次测：球从 (0, 0, 300) 落下，停在 (-320, 469.5, 25) —— **横向漂了 568 cm**。**

**我以为原因是「球会滚」。**

---

## 二、🎯 第一组对照：球 vs 立方体（同条件）

**两个都是官方素材（`/Engine/BasicShapes`），同一起始高度 z=300，同一材质，零初速度，
分别放在 (-300, 0) 和 (300, 0)。**

**实测结果（✅ 同一次 simulate 里同时落下）：**

```
球     fell 275.0 cm, drifted  20.0 cm horizontally, speed 0.00
立方体  fell 275.0 cm, drifted  83.1 cm horizontally, speed 0.00
```

| 物体 | 下落 | **横向漂移** | 终止速度 |
| --- | --- | --- | --- |
| **球** | 275 cm | **20.0 cm** | 0 |
| **立方体** | 275 cm | **83.1 cm** | 0 |

**→ 🔴 立方体漂得**比球远 4 倍** —— 和我的假设**相反**。**

**→ 而且这一轮的球只漂 **20 cm**，同一个球、同样的高度，上一轮漂了 **568 cm**。**

**→ 两次差异巨大，说明结果**不确定**。**

**可能的解释（**未验证**）：**
- 立方体落地时可能有棱角接触，产生翻滚/弹跳
- 球落地后滚动能量小、自纠正快
- 第一次那 568 cm 可能是残留速度或撞到别的东西（那轮球在场地正中）

---

## 三、🎯 第二组对照：加阻尼

**同一个球，从 (0, -400, 300) 落下，加：**
```
linear damping  5.0    （默认 0.01）
angular damping 20.0   （默认 0.0）
```

**实测：**

```
damped sphere at (0.0, -400.0, 25.0)
    fell 275.0 cm, drifted 0.0 cm
```

| | 横向漂移 |
| --- | --- |
| **无阻尼** | **20.0 cm** |
| **线性 5.0 + 角阻尼 20.0** | **0.0 cm** |

**→ 阻尼把横向漂移**降到零**。**

**→ 这就是「让掉落物停在原地」的**可操作答案**。**

---

## 四、结论

| 结论 | 强度 |
| --- | --- |
| **球会横移，加阻尼可以消除** | ✅ **实测（20 → 0 cm）** |
| 立方体**比球**漂得远 | ✅ 实测（83 vs 20），**机制未查清** |
| 第一次的 568 cm 是**可复现的环境问题** | ❌ **不可复现**，同一条件第二次只有 20 cm |
| 「球会滚、方块不会」 | ❌ **被推翻** |

**🔴 对上一块结论的更正：**
> 我上一条写「球落地后滚了 5 米，值得单独查」。
> **现在查明：那不是球的固有行为。** 同一条件重测只有 20 cm，而方块反而漂了 83 cm。
> **→ 那 568 cm 是**一次性的异常**，不是规律。**

---

## 五、可操作的做法（给项目用）

**如果要让掉落物停在掉落点附近：**

```python
component.set_linear_damping(5.0)
component.set_angular_damping(20.0)
```

**API 位置（✅ 从本地 API 镜像核实）：**
```
PrimitiveComponent.set_linear_damping(rate)
PrimitiveComponent.set_angular_damping(rate)
PrimitiveComponent.get_linear_damping() / get_angular_damping()
PrimitiveComponent.set_phys_material_override(new_phys_material)   ← 改摩擦
```

**⚠️ 代价：阻尼高会让人感觉「东西粘住了」。** 项目里拾取距离只有 100–150 cm 时，
**5.0 / 20.0 的阻尼值得试，但要看手感。**

## 七、这一块学到什么

**1. 加阻尼能把横向漂移从 20 cm 降到 0。**
可操作、已验证。

**2. 形状假设错了。** 立方体比球漂得更远。

**3. 一次异常不能当规律。**
568 cm 只出现过一次，重测是 20 cm。**当时应该立刻重测，而不是写进文档当结论。**

**4. PIE 的状态要显式管理。**
每次操作前查 `is_in_play_in_editor()`，结束要等它真的结束。
