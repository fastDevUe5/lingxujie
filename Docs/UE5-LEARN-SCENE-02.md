## 三、🎯 Lumen 在户外的作用：**20.45% 的像素**

### 3.1 方法

```
1. 相机固定，截 shot_comp.png（Lumen 开）
2. r.Lumen.DiffuseIndirect.Allow 0
3. 同机位截 shot_nolum.png
4. 像素对比
5. 恢复 Lumen 开
```

### 3.2 结果（✅）

```
pixels differing by more than 8: 165,986 (20.45%)
mean absolute channel delta: 4.006
VERDICT: the two captures differ in a region, not everywhere
```

**→ **户外场景里，关掉 Lumen 有 20.45% 的像素变化。****

### 3.3 变化在哪（对比两张图）

| 位置 | Lumen **开** | Lumen **关** |
| --- | --- | --- |
| **云层** | 粉紫色层次分明，有立体明暗 | **扁平、均匀的橙色** |
| **地面** | 有渐变的暖棕 | **更平、更浅** |
| 物体受光面 | 有从天空来的补光 | 补光消失，更死板 |

**→ Lumen 的间接光照把天空的**粉紫**散射进了场景，
关掉之后天空只剩直射太阳光 → 云变扁平、地面变浅。**

## 四、🔴 和第 19 轮的对照：同一功能，两个场景，两个结论

| | 室内密封盒子（第 19 轮）| **户外原野（本轮）** |
| --- | --- | --- |
| 场景 | 10 actor，无天空 | **14 actor，有天空/云/雾** |
| Lumen 关掉的帧时间 | 8.468 ms | — |
| Lumen 开着的帧时间 | 8.360 ms | — |
| **帧时间差异** | **噪声（0.1ms）** | — |
| **像素差异** | 没测（那次只量时间）| **20.45%** |

**→ 关键区别：**
- 第 19 轮量的是**帧时间**，而编辑器里帧时间被睡眠主导 → **测不出来**
- 本轮量的是**像素**，不受睡眠影响 → **测出来了**

**→ 同一个功能，**换一个判据就能测到**。**

**→ 这补上了第 19 轮的遗憾：**Lumen 不是没效果，是当时用错了尺子。****

## 五、这一块学到什么

**1. 🎯 室内和户外的 Lumen 表现完全不同。**
室内靠点光源（间接光贡献小），户外靠天光（间接光贡献大 → 20.45%）。

**2. 🔴 判据要匹配问题。**
问「有没有视觉效果」→ 量像素。
问「值多少毫秒」→ 量时间（且必须避开睡眠主导的编辑器环境）。

**3. 同一次改动可以用两种判据，得到互补的结论。**
第 19 轮 + 本轮合起来才完整：**Lumen 有价值（画面 20.45%），但在这台机器上量不到时间差。**

**4. 控制台键入可能悄无声息地失败。**
脚本没输出 ≠ 脚本没内容 —— 要看 `Cmd: py` 那行确认命令送到了。
