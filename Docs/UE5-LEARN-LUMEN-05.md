# UE5 学习 · Lumen（第五块）：🔴 我测错了对象

> **上一轮我得出结论：「10 cm 天花板漏光，60 cm 不漏，机制是距离场体素分辨率」。**
>
> **这一轮发现：**这个练习关卡里根本没有距离场。**
> **观察是对的，机制解释是错的。**
>
> **日期：2026-11-27 · UE 5.8.4**

---

## 一、怎么发现的

**我本来要做另一个实验（量化「1 cm 放大 500×」的距离场开销），
于是先读图集 —— 结果发现：**

```
Mesh Distance Field Atlas 1024x1024x8 = 8.0Mb (目标上限 256.0Mb)
  剩余 8.0Mb, 浪费 0.0Mb
  Mip0: 0.0Mb, 28.1%
  Mip1: 0.0Mb,  0.0%
  Mip2: 0.0Mb,  0.0%
```

**→ **8 MB 总共、8 MB 剩余 = 一个距离场都没建。****

**而主关卡里是 64 MB 用了 39 MB（25 MB 剩余）—— 那边有距离场。**

**再查开关：**
```
r.GenerateMeshDistanceFields = "1"   LastSetBy: ProjectSetting
```
**→ 开关是开的，但这个关卡里没有资产有距离场数据。**

---

## 二、为什么

**`r.GenerateMeshDistanceFields = 1` 只表示「允许为需要距离场的网格**构建**距离场」。
距离场是**按资产**在导入/烘焙时生成的。**

**练习关卡用的是：**
```
/Engine/BasicShapes/Cube        ← 引擎基础形状，没有烘距离场
/Engine/EngineMeshes/s_cube_1cm ← 同上
```

**→ 引擎自带的基础形状**不带距离场数据**。**

**→ 所以这个关卡里 Lumen 软件光追**没有距离场可追踪**。**

---

## 三、那上一轮看到的光斑是什么

**我做了漏掉的对照：**把灯强度设为 0，同机位拍一张**。**

```
灯强度 5000 → 顶面大片光斑
灯强度    0 → 画面全黑（只剩编辑器网格）
差异：9.54% 像素，平均 delta 6.893
```

**→ 光斑**确实**是由那盏灯产生的。观察没错。**

**→ 但没有距离场，所以不是距离场漏光。**

**→ 最可能的机制：**可移动点光源的阴影贴图偏移（shadow bias）。**
薄面（10 cm）在阴影贴图上深度差太小，被 bias 判为「受光面」，光就「穿」过去了。
加厚到 60 cm，深度差足够大，就不再穿透。**

**⚠️ 这是**直接光**的阴影问题，和官方说的**间接光（GI）距离场漏光**是两件事。**

## 六、这一轮真正学到什么

**1. `r.GenerateMeshDistanceFields = 1` **不等于**「场景里有距离场」。**
距离场是**按资产**生成的，引擎基础形状没有。

**2. 判断「有没有距离场」的唯一可靠方法：读图集。**
`r.DistanceFields.LogAtlasStats 1` 看「剩余 vs 总量」：
- 剩余 < 总量 → 有距离场
- **剩余 == 总量 → 一个都没有**

**3. 实验前必须确认被测对象真的存在。**
我搭了个「Lumen 实验关卡」，但里面根本没有 Lumen 需要的距离场。
**→ 这等于在一个没有水的池子里测游泳。**

**4. 光穿透薄面有两个不同机制：**
| 机制 | 影响 | 触发条件 |
| --- | --- | --- |
| **阴影贴图 bias** | **直接光**穿透 | 薄 + 可移动光源 |
| **距离场分辨率** | **间接光（GI）**漏 | 薄 + 软件光追 |

**→ 我把第一个当成了第二个。**
