## Control Rig Rig and Animate characters in real-time using Control Rig. On this pageUnreal Engine provides a suite of animation tools for you to rig and animate characters directly in-engine, called Control Rig. Using Control Rig, you can bypass the need to rig and animate in external tools, and instead animate in Unreal Editor directly. With this system, you can create and rig custom controls on a character, animate in Sequencer, and use a variety of other animation tools to aid your animating process.This page contains links to documentation covering Unreal Engine's Control Rig tools and real-world examples of their workflows.
