# UE5 学习 · 补读（六）：太阳高度角扫描 —— Rayleigh 的教科书级验证

> **上一篇只试了 4 个散射参数。这一篇换了个更根本的变量：**太阳本身的高度**。
> **结果是本系列**最干净的一组单调数据**。**
>
> **日期：2026-11-27 · UE 5.8.4**

---

## 一、为什么扫太阳，而不是扫参数

**上一篇的发现是：同一 Rayleigh 值，白天和日落效果相反。**
**→ 那说明真正的自变量是**太阳高度角**（它决定光在大气里走多远），
Rayleigh 只是放大器。**

**→ 所以最干净的实验是：**固定所有散射参数，只扫太阳俯仰**。**

---

## 二、实验设置

| 项 | 值 |
| --- | --- |
| 关卡 | `/Game/Learning/L_Scene01` |
| 散射参数 | **全默认**（Rayleigh 0.0331 / Mie 0.003996 / anisotropy 0.8）|
| 连续变量 | `DirectionalLight` 的 **pitch**：-5° → -15° → -30° → -45° → -60° |
| 相机 | (0, -800, 150)，pitch +10（能看到地平线以上）|
| 测量 | 画面上 40% 区域的平均 RGB，以及 **R−B**（红减蓝，越负越蓝）|

**⚠️ pitch 越负 = 光线越朝下 = **太阳越高**。**

---

## 三、🎯 实测数据（✅ 单调，无例外）

| 太阳俯仰 | 天空平均 RGB | **R − B** | 解读 |
| --- | --- | --- | --- |
| **-5°** | (190.3, 199.7, 208.7) | **−18.4** | **太阳近地平，最暖/最中性** |
| -15° | (142.3, 171.4, 195.2) | −52.8 | 开始变蓝 |
| -30° | (109.9, 144.7, 178.3) | −68.5 | 明显蓝 |
| -45° | ( 95.6, 131.1, 168.2) | −72.6 | 深蓝 |
| **-60°** | ( 89.4, 124.9, 163.8) | **−74.4** | **太阳高悬，最蓝** |

**→ R−B 从 −18.4 单调降到 −74.4，**跨度 56**。
→ 同时整体亮度从 190 降到 89 —— **太阳越低，天空越暗。**（显然）**

### 3.1 换算成「蓝的程度」

```
-5°   R−B = -18.4   → 近乎中性（R 和 B 只差 18）
-60°  R−B = -74.4   → 强蓝（B 比 R 高 74）
```

**→ 相差 **4 倍**。**

## 四、🎯 这正好验证了文档那句话

**文档原文：**
> **「at sunset, it appears red because light rays need to travel further in the atmosphere.
> After long distances, all blue light is scattered away before other colors,
> resulting in colorful sunsets full of yellow, orange, and red colors.」**

**实验怎么验证它：**

| 文档断言 | 实验证据 |
| --- | --- |
| 日落时光路更长 | **pitch -5° = 太阳在水平方向，光几乎平行地面穿过大气** |
| 蓝光先被散射掉 | **R−B 从 −74（蓝）变到 −18（中性），蓝确实少了** |
| 剩下黄橙红 | **-5° 时 R 是 190，B 是 208 —— R 相对升高，画面转暖** |

**→ 五个数据点，一个方向，没有反复。**这是本系列第一次拿到这么干净的答案。****

## 六、这一篇学到什么

**1. 🎯 找对自变量，比调参数更重要。**
上一篇我在调 Rayleigh/Mie（放大器），这一篇扫太阳高度（真正的自变量），
**结果干净得多。**

**2. 🔴 太阳俯仰越负 = 太阳越高。**
`pitch -5` 是太阳贴近地平线（日落），`pitch -60` 是太阳高悬（正午）。
**这个符号方向我一开始也犹豫过 —— 它和直觉相反。**

**3. 🎯 「R−B」是一个好判据。**
它把「偏暖/偏蓝」压缩成一个数字，而且能跨图比较。
**比肉眼看图可靠，比看平均亮度有信息量。**

**4. 太阳高度不只改天空，改的是**整个场景色温**。**
物体、地面、云全跟着变。

**5. 五个点单调，这才是「有说服力」的数据。**
之前很多实验只有两组对比，说服力弱得多。
