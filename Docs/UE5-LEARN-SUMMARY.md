## 六、🎯 28 条更正里最有价值的三条

**1. 🔴 「睡眠主导的帧不能用来做优化对比」**
8.36 ms 里 7.94 ms 是 Stall。**在睡眠的帧上做实验只能得到假阴性。**
**→ 推广：任何测量之前，先确认被测的量**有没有在动**。**

**2. 🔴 「换一个判据就能测到」**
同一个 Lumen：量帧时间 = 噪声；量像素 = **20.45%**。
**→ 判据要匹配问题，不是匹配习惯。**

**3. 🔴 「存储的值 ≠ 生效的值」**
`auto_exposure_method` 读回 `AEM_MANUAL`，但画面正常 —— 因为 `override_* = False`。
**→ 读状态时要问「这个值**当前生效吗**」。**

## 九、这个阶段的真实价值

**不是「学了 22 篇」，而是**建立了一套可复用的方法**：**

```
读文档（找可验证的断言）
  → 查源码（确认真实机制）
    → 找判据（这个断言能用什么量出来）
      → 做对照（只改一个变量）
        → 记录更正（我原来错在哪）
```

**这套方法在 8 个域上都用过，并且**每次都产出了具体数字或画面**。**

**→ 它的价值在于：**下一次遇到陌生问题，我知道从哪下手**，
而不是「我记住了多少 API」。**
