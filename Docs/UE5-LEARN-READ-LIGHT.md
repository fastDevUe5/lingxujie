## 二、🎯 文档的核心事实：强度单位是 **lux**

> **「Intensity | Maximum illumination from the light, **in lux**」**

**→ **lux 是照度的物理单位（流明/平方米）。****

**真实世界的参考值：**

| 场景 | 照度 |
| --- | --- |
| 晴天直射阳光 | **~100,000 lux** |
| 阴天 | ~10,000 lux |
| 明亮室内 | ~500 lux |
| 月光 | ~0.3 lux |

---

## 三、🔴 我的场景：太阳 = **8 lux**

**我在搭场景时把 `intensity` 设成 8，因为「看着合适」。**

**→ 8 lux 比**明亮室内还暗**，比真实阳光暗 **12,500 倍**。**

**但画面看着是正常的日落。为什么？**

---

## 四、🎯 实测：把强度提高会怎样

**只改 `intensity`，其他全不动：**

| intensity | 全画面平均亮度 | 平均 RGB | 观察 |
| --- | --- | --- | --- |
| **8** | **150.9** | (138, 152, 163) | ✅ 正常日落 |
| **800** | **247.4** | (244, 248, 250) | ⚠️ 几乎全白 |
| **100,000** | **254.1** | (254, 254, 254) | ❌ **纯白过曝** |

**→ 强度提高 100 倍就接近全白，提高 12,500 倍就**完全白掉**。**

**→ **自动曝光**没有**完全补偿**。**

---

## 五、🎯 为什么没补偿 —— 算一下就清楚

**之前读到的后处理曝光设置（✅ 实测）：**
```
auto_exposure_min_brightness    0.03
auto_exposure_max_brightness    8.0
auto_exposure_bias              1.0
exposure_offset                 1.0
b_override_exposure_offset      False
```

**自动曝光的适应范围：**
```
8.0 / 0.03 = 267 倍 = log2(267) = 8.06 档
```

**而我的改动跨度：**
```
100,000 / 8 = 12,500 倍 = log2(12500) = 13.61 档
```

**→ **13.61 档 > 8.06 档 → 超出 5.5 档 → 曝光钳死在最大亮度 → 白掉。****

**→ 这就是「为什么提高强度会过曝」的**定量解释**。**

---

## 六、🔴 这个场景的真实性质

**说清楚这个场景的曝光是怎么工作的：**

| 事实 | 含义 |
| --- | --- |
| 太阳 = 8 lux（真实值 1/12500） | **不是物理正确的设定** |
| 天空由 SkyAtmosphere 提供 | 它的亮度是物理量级的 |
| 自动曝光把两者「配平」到看着舒服 | **这是视觉凑出来的，不是量出来的** |
| 曝光范围 8 档 | **能容纳 267 倍的变化** |

**→ 结论：这个场景**在 intensity 8 这个特定值上好看**，
但这个值**没有物理依据**，且**一旦改动超过 8 档就崩**。**

**→ 正确做法应该是：**用物理量级的光强（比如阳光 100,000 lux），
然后靠曝光值/EV 调整画面明暗**，而不是把光源调到极暗。**

---

## 七、这一篇学到什么

**1. 🔴 lux 是照度单位，真实阳光约 100,000。**
**我设 8 是「看着合适」，不是「物理正确」。**

**2. 🎯 自动曝光有**适应范围上限**（这里是 8.06 档 = 267 倍）。**
超出就钳死、过曝。**这个范围是可以读出来的（min/max brightness）。**

**3. 🎯 「看着对」≠「参数对」。**
**这是本系列反复出现的一类问题：用视觉判断代替测量。**

**4. 🔴 正确的光照工作流：**
光源用物理量级 → 用曝光/EV 控制画面亮度 → 而不是反过来。**

**5. 8 档（267 倍）这个数字说明了「为什么小改动没事、大改动就崩」——
它是**剂量阈值**。**
